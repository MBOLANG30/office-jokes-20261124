A make.fun entry for "Make the AI Judge Laugh: Office Jokes". The program writes a single original one-line joke about office life — three years on mute in meetings, as seen by HR and by a therapist — to `entry.txt`, where an AI judge compares it head to head against the other entries.

## Run it

```sh
node main.ts
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset).
